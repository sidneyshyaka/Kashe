# Kashe
CS451 Senior project


   A point-of-sale app for small shops. Handles sales, inventory, credit and debt tracking, and staff sign-in with manager and employee roles.

   ## Status
   Planning stage.

   ## Planned features
   - Sign-in with manager and employee roles
   - Sales and checkout
   - Inventory tracking
   - Credit and debt tracking
   - Sales reports

   ## Planned tech stack
   - Next.js (React)
   - Supabase (database and auth)
   - Vercel (hosting)
